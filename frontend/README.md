# Frontend placeholder

This folder is a placeholder for a Svelte frontend app. For now there's a minimal static page under frontend/public/index.html that demonstrates the API use.

To bootstrap a Svelte app (recommended):

1) cd frontend
2) npm create vite@latest . --template svelte
3) npm install
4) npm run dev

When you have a built frontend, place the build output in frontend/public so the backend can serve it from the StaticFiles mount.
